# B站清理工具（Tampermonkey 脚本）

## 简介

**B站清理工具** 是一款基于 Tampermonkey 的用户脚本，专为 Bilibili 用户设计，提供一键批量清理消息、私信、历史记录、系统通知等功能。脚本自带悬浮菜单与多主题切换，支持自动清理计划、宽限撤销机制，操作简单，界面友好。

> B站全站匹配：`*://*.bilibili.com/*`

## 功能特色

- 🧹 批量清理 B站消息（回复、赞我、艾特、私信、历史、系统通知）
- ⏱️ 自动清理（支持 每次/每天/每周 频率 + 当天/三天/一周/全部清理 保留策略）
- ↩️ 宽限确认/撤销机制（3 秒可撤销倒计时，带环形进度动画）
- 💧 水滴冷凝特效（面板内 16 个随机水珠动画）
- 🔄 请求重试与频率限制防护（3 次重试 + 指数退避 + -412 自动重试）
- 🎨 多主题切换（dark / 粉 / 蓝 / 绿 / 紫 五套主题）
- 🪟 悬浮菜单，支持标题栏拖动

## 安装方法

1. **安装 Tampermonkey 插件**
   - Chrome/Edge/Firefox 浏览器均可在扩展商店搜索并安装 [Tampermonkey](https://www.tampermonkey.net/)。

2. **安装本脚本**
   - 方法一：在 [GreasyFork](https://greasyfork.org/zh-CN) 或 [GitHub](https://github.com/zisull/Tampermonkey-BiliClean) 找到本脚本，点击"安装"。
   - 方法二：手动复制 `biliclean.js` 脚本内容，添加到 Tampermonkey 新建脚本中保存。

3. **刷新 B站页面**，右下角会出现悬浮按钮，即可使用。

## 使用说明

1. 点击右下角悬浮按钮，弹出菜单。
2. 选择需要清理的消息类型（回复、赞我、艾特、私信、历史、系统），点击"立即清理"。
3. 弹出 3 秒倒计时确认条，可点击"撤销"取消；倒计时结束后自动执行清理。
4. 清理进度和结果会实时显示在面板中。
5. 展开"自动清理"区域，可设置清理频率和保留策略，实现定期自动清理。
6. 可切换不同主题风格，体验更佳。

## 常见问题

- **Q: 清理失败/无效？**
  - 请确保已登录 B站，且网络正常。脚本内置 3 次重试与指数退避机制，遇到频率限制（-412）会自动等待重试。若长时间未登录或 Cookie 失效，建议重新登录。
- **Q: 脚本无法加载？**
  - 请确认 Tampermonkey 已启用，且脚本已安装并在 B站页面生效。
- **Q: 主题切换无效？**
  - 主题切换后会自动保存到本地，若未生效可尝试刷新页面。
